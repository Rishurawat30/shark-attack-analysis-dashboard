#  Shark Attack Analysis Dashboard | Excel

##  Project Overview
This project analyzes recorded shark attack incidents using Microsoft Excel. An interactive dashboard was created to explore patterns across countries, activities, shark species, attack types, fatality outcomes, and yearly trends.

##  Tools & Skills Used
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and interactive filters
- Excel formulas and calculations
- Data cleaning and handling missing values
- Dashboard design and data visualization

##  Key Questions Explored
- Which countries have the highest number of recorded shark attack incidents?
- Which countries have the highest number of fatal incidents?
- Which activities are most frequently associated with recorded shark attacks?
- Which shark species have the most recorded incidents where species information is available?
- How does fatality rate differ by attack type?
- Which years show unusually high recorded attack volumes?
- How do recorded incidents differ by gender?

##  Dashboard Features
- KPI cards displaying total incidents, fatal incidents, countries represented, and overall fatality rate
- Top 10 countries by recorded shark attack incidents
- Top 10 countries by fatal incidents
- Most frequently recorded activities
- Shark species with the most recorded incidents where species information is available
- Yearly attack volume trends
- Fatality rate comparison by attack type
- Gender-based incident comparison
- Interactive slicers for exploring the data

##  Key Learnings
- Creating PivotTables and PivotCharts to summarize data
- Applying Top 10 value filters
- Calculating fatality rates using known fatality outcomes
- Handling missing information without removing records unnecessarily
- Identifying trends and patterns in recorded incidents
- Designing an interactive Excel dashboard

##  Important Notes
- The analysis represents recorded incidents in the dataset, not the actual risk of a shark attack.
- Some records have missing activity, injury, location, species, or other information.
- Fatality rates are calculated using records with known fatality status (`Y` or `N`).
- Findings depend on the completeness and quality of the available data.
